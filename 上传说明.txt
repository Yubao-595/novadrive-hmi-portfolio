NovaDrive HMI 作品集｜GitHub Pages 上传包

你只需要：
1. 解压这个压缩包。
2. 打开 GitHub 仓库 Yubao-595/novadrive-hmi-portfolio。
3. 点击 Add file → Upload files。
4. 把解压后看到的全部内容拖进去（index.html、styles.css、app.js、favicon.svg、assets 文件夹、上传说明.txt）。
5. 页面下方点击 Commit changes。

不要把压缩包本身直接上传，也不要再套一层文件夹。

上传完成后，再进入：
Settings → Pages → Build and deployment
Source 选择 Deploy from a branch
Branch 选择 main，文件夹选择 /(root)，点击 Save。

作品集访问地址：
https://yubao-595.github.io/novadrive-hmi-portfolio/
